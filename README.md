# Star Trek: Alter Course

**Star Trek: Alter Course (ST:AC)** is a single-player, fan-made Star Trek strategy and starship-command game inspired by EGA Trek, Super Star Trek, and Netrek, built with Godot and C#.

## Project status

Early development.
